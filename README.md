# CS-360-Mobile-App
CS 360 Mobile Architecture and Programming portfolio project

For CS 360, I developed a Weight Tracker app using Java and Android Studio. The goal was to create an application that allows users to record their weight, set personal goals, and track their progress over time. I wanted to make something that was simple to use without having too many unnecessary features. The app includes account creation, login, a database for storing weight entries, and the ability to update or delete information.

## What screens and features were necessary to support user needs?

I designed a login screen where users could sign in or create an account. I also created a dashboard where users could enter their weight, view previous entries, and manage their weight goals. I wanted the layout to be easy to understand so users wouldn't have to search through multiple screens just to record their progress. I tried to keep the design straightforward and make the most important features easy to access.

## How did you approach coding your app?

I started by designing the user interface in Project Two before adding the functionality in Project Three. I worked on connecting the buttons and screens to the Java code and then incorporating the database. Breaking the project into smaller tasks helped because trying to get everything working at once would have been overwhelming. This is something I plan to continue doing in future projects because it makes troubleshooting easier.

## How did you test your code, and what did testing reveal?

I tested my app using the Android Studio emulator. I worked through creating an account, logging in, and saving weight entries to make sure the app was responding correctly. I also worked on the SMS notification feature and tested the permission settings. The app displayed that a message was sent, although I wasn't able to confirm that it was actually delivered. Testing helped me realize that just because the code builds successfully doesn't mean every feature is working exactly as expected.

## Where did you have to innovate to overcome a challenge?

One of the biggest challenges was getting the different parts of the app to work together. Designing the screens wasn't as difficult as connecting them to the database and making sure the information was saved correctly. I had to go back through my code, figure out where things weren't connecting, and make adjustments. I also had to work through issues with testing the SMS feature. Instead of trying to fix everything at once, I focused on individual problems until I could make progress.

## What part of your app best demonstrates your skills?

I think the database functionality is one of the strongest parts of my Weight Tracker app. Being able to create an account, log in, and save weight information showed me how much I had learned about connecting the user interface to the code behind it. Before this course, I hadn't worked through the entire process of developing an Android application like this. Even though there are things I would still improve, I'm happy that I was able to take an app from the initial design to a working project.
